Hallo! Ich bin CipherChat – ein winziges Sprachmodell, das deine Nachricht nur verschlüsselt sieht. Probier eine der Beispielfragen. (Ich antworte kurz, oft einsilbig.)

Was der Server sieht nur Ciphertexts

Pro Token: 1 Ciphertext hoch (≈2,3 MB), bei Bedarf 1 Ciphertext mit verschlüsselten Logits zurück. Der Server kennt nur Größe, Hash und Rechenzeit – genau wie bei HTTPS bleibt nur die Länge sichtbar.

Nur auf deinem Gerät entschlüsselt

Der Client entschlüsselt die Logits mit dem Secret Key, wählt das nächste Zeichen (argmax) und verschlüsselt es für den nächsten Schritt.

So funktioniert's

1 · HandshakeDer Client erzeugt ein CKKS-Schlüsselpaar. Nur öffentliche Parameter + Evaluation-Keys gehen an den Server – wie ein TLS-Handshake, nur ohne dass der Server je entschlüsseln kann.
2 · VerschlüsselnJedes Zeichen wird als One-Hot-Vektor in 8192 Slots gepackt und verschlüsselt (128-Bit-Sicherheit).
3 · Blind rechnenDer Server wertet einen FHE-freundlichen Transformer aus: polynomielle Attention, Quadrat-Aktivierung, verschlüsselter KV-Cache.
4 · EntschlüsselnZurück kommen verschlüsselte Logits. Nur der Client kann sie lesen und das nächste Token wählen.
